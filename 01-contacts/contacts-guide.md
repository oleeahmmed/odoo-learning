# Contacts — একদম সহজ গাইড
### রহিম ভাইয়ের খাতা: মানুষ লিখি, দোকান লিখি

---

## আগে একটা ছোট গল্প

রহিম ভাইয়ের দোকান — **রহিম ট্রেডার্স**।

আগে খাতা এমন ছিল:

```
এক খাতায়: ঢাকা ইলেকট্রনিক্স
আরেক খাতায়: করিম ভাইয়ের নম্বর
আরেক খাতায়: সানরাইজ — বাকি টাকা
```

সব গোলমাল।

Odoo বলে:

> একটাই জায়গা — **Contacts**।  
> শুধু বলো: এটা **দোকান** নাকি **মানুষ**।

# পাঠ ১ — নতুন Contact খুললে কী দেখবেন?

```
Contacts → New
```

উপরে দুটো বাটন:

```
○ Individual     ○ Company
```

এটাই সবচেয়ে বড় সিদ্ধান্ত।

---

## Company মানে কী?

**দোকান / কোম্পানি / অফিস** — মানুষ নয়।

### গল্প

রহিম ভাই মাল কেনেন **ঢাকা ইলেকট্রনিক্স** থেকে।  
এটা একটা দোকান। সাইনবোর্ড আছে। বিল দোকানের নামে কাটে।

```
তাই বাছাবেন → ○ Company
নাম লিখবেন → Dhaka Electronics Ltd
```

আরেক গল্প: **সানরাইজ স্টোর** আপনার কাছ থেকে কেনে — ওটাও দোকান।

```
তাই → ○ Company
```

---

## Individual মানে কী?

**একজন মানুষ।**

### গল্প

ঢাকা ইলেকট্রনিক্সের ম্যানেজার **করিম**।  
রহিম ভাই ফোন করেন করিমকে। করিম নিজে দোকান নন — তিনি মানুষ।

```
তাই বাছাবেন → ○ Individual
নাম → করিম চৌধুরী
Company Name → Dhaka Electronics Ltd  (কোন দোকানের লোক)
Job Position → Sales Manager
```

আরেক গল্প: পাশের **মামা হাবিব** মাঝে মাঝে কেনেন। কোনো দোকান নেই।

```
তাই → ○ Individual
Company Name → খালি রাখুন
```

---

## কখন কোনটা? (এক লাইনে)

```
দোকান / কোম্পানি          → Company
মানুষ (কর্মী বা ব্যক্তি)   → Individual
```

| কে? | কোনটা? |
|---|---|
| ঢাকা ইলেকট্রনিক্স | Company |
| করিম ম্যানেজার | Individual |
| সানরাইজ স্টোর | Company |
| মামা হাবিব | Individual |
| টঙ্গী গুদামের ঠিকানা | দোকান খুলে ভিতরে Address যোগ |

# পাঠ ২ — শুধু Contacts বসানোর পর কী কী লিখতে পারবেন?

এখন আপনার কাছে শুধু Contacts।  
নতুন Contact-এ মূলত এগুলোই পাবেন:

```
☑ Individual বা Company বাছাই
☑ নাম
☑ ঠিকানা (রাস্তা, শহর, দেশ)
☑ ফোন, মোবাইল, ইমেইল
☑ ছবি / লোগো
☑ Tax ID (টিন) — চাইলে
☑ Job Position — Individual হলে
☑ Company Name — Individual হলে (কোন দোকানের লোক)
☑ Tags (স্টিকার)
☑ Salesperson (কে দেখাশোনা করবে)
☑ Notes (নিজের মনে রাখার কথা)
☑ Contacts ট্যাব — দোকানের ভিতরে মানুষ/ঠিকানা যোগ
```

### এখন পাবেন না (এটা স্বাভাবিক)

```
❌ Is a Customer টিক
❌ Is a Vendor টিক
❌ Pricelist
❌ Payment Terms
❌ উপরে “Sales: 5” বা “Purchase: 3” বাটন
```

কারণ সেগুলো **অন্য App** বসালে আসে। নিচে গল্পে বলছি।

# পাঠ ৩ — তাহলে Customer / Vendor কীভাবে হয়?

আপনি ঠিকই বলেছেন — **সেট করার টিক দেখছেন না।**

Odoo 17 এভাবে চালায়:

## গল্প দিয়ে বোঝা

### কাস্টমার হওয়া

```
১. Contacts-এ সানরাইজ স্টোর লিখলেন
   → এখনো শুধু একটা নাম। এখনো “কাস্টমার” হিসাব জোরে জোরে লাগে না।

২. পরে Sales App বসিয়ে সানরাইজকে মাল বেচলেন (Sales Order)
   → Odoo বুঝল: এদের সাথে বেচা হয়েছে
   → এরা কাস্টমার

৩. বিল কাটলে (Invoicing) আরও পরিষ্কার হয়ে যায়
```

### ভেন্ডর হওয়া

```
১. Contacts-এ ঢাকা ইলেকট্রনিক্স লিখলেন

২. পরে Purchase App দিয়ে তাদের কাছ থেকে মাল কিনলেন
   → Odoo বুঝল: এদের কাছ থেকে কেনা হয়েছে
   → এরা ভেন্ডর
```

### দুটোই হওয়া

```
পদ্মা ট্রেডার্স:
  একদিন তাদের কাছে বেচলেন  → কাস্টমার দিক
  একদিন তাদের কাছ থেকে কিনলেন → ভেন্ডর দিক

আলাদা দুই Contact লাগে না।
একই নামে দুই রকম কাজ করলেই দুটোই।
```

### সহজ কথা

```
Contact বানানো  = খাতায় নাম লেখা
Customer হওয়া = তার কাছে কিছু বেচা
Vendor হওয়া   = তার কাছ থেকে কিছু কেনা
দুটোই         = দুই কাজই করা
```

টিক দিয়ে সেট নয় — **কাজ করে সেট।**

# পাঠ ৪ — অন্য App বসালে Contact-এ কী যোগ হয়?

ভাবুন Contact = একটা খালি খাতার পাতা।  
প্রতিটা App = নতুন কলম।

---

## Sales বসালে

```
Apps → Sales → Install
```

**কী যোগ হয়**

```
• Contact খুললে উপরে “Sales” বাটন
• সংখ্যা = এই নামে কত অর্ডার হয়েছে
• ক্লিক করলে সেই অর্ডারগুলো দেখা যায়
```

**কীভাবে কাজ করে (গল্প)**

```
সানরাইজকে ১টা অর্ডার দিলেন → Sales বাটন দেখায় 1
আরও ২টা দিলেন             → দেখায় 3
```

নাম শুধু লিখে সংখ্যা বাড়ে না। **অর্ডার করতে হয়।**

---

## Purchase বসালে

```
Apps → Purchase → Install
```

**কী যোগ হয়**

```
• “Purchases” বাটন
• Buyer (কে কিনবে — আপনার লোক)
```

**গল্প**

```
ঢাকা ইলেকট্রনিক্স থেকে PO দিলেন → Purchases সংখ্যা বাড়ে
```

---

## Invoicing বসালে

```
Apps → Invoicing → Install
```

**কী যোগ হয়**

```
• Accounting ট্যাব
• Payment Terms (কত দিনে টাকা)
  - কাস্টমার কবে দেবে
  - আপনি ভেন্ডরকে কবে দেবেন
• Invoice / Bill বাটন
```

**গল্প**

```
সানরাইজকে বললেন “১৫ দিনে টাকা”
→ তার Contact-এ Payment Terms = 15 Days
→ নতুন বিলে সেটা নিজে বসে যায়
```

---

## Pricelist কী? (সহজ)

```
একই চাল:
  সানরাইজকে পাইকারি দাম
  মামাকে খুচরা দাম
```

এই দামের তালিকা = **Pricelist**।

**কখন দেখা যায়**

```
Sales বসাতে হবে
+ Settings → Sales → Pricelists চালু করতে হবে
```

শুধু Contacts-এ এই ঘর থাকে না।

**কখন ব্যবহার**

```
পাইকারি কাস্টমার → Wholesale Pricelist
সাধারণ            → Public Pricelist
```

দোকান (Company)-এ সেট করা ভালো। কর্মীর উপর নয়।

---

## ছোট চার্ট (মনে রাখার জন্য)

```
কী বসালেন        Contact-এ নতুন কী পাবেন
────────────────────────────────────────
Contacts         নাম, ঠিকানা, ফোন, ট্যাগ, মানুষ যোগ
Sales            Sales বাটন + অর্ডার সংখ্যা
Purchase         Purchases বাটন + Buyer
Invoicing        Payment Terms, হিসাব, বিল বাটন
Sales+সেটিংস     Pricelist ঘর
```

```

```

# আজ যা মনে রাখবেন

```
১. Company = দোকান | Individual = মানুষ

২. শুধু Contacts = নাম–ঠিকানা–ফোন লেখা যায়
   Customer/Vendor টিক নেই — স্বাভাবিক

৩. কাস্টমার = তার কাছে বেচলে হয়
   ভেন্ডর   = তার কাছ থেকে কিনলে হয়
   দুটোই   = দুই কাজই করলে হয়

৪. Sales বসালে → Sales সংখ্যা দেখা যায়
   Purchase বসালে → Purchase সংখ্যা দেখা যায়
   Invoicing বসালে → টাকার নিয়ম (Payment Terms) আসে

৫. Pricelist = আলাদা দামের তালিকা — Sales + সেটিংস লাগে
```

## পরের গল্প

Inventory পার্টে গুদাম ও পণ্য শিখবেন।

আজকের কাজ শুধু: **সঠিকভাবে নাম লেখা — দোকান নাকি মানুষ।**
